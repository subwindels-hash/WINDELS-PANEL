## 6. Key Conventions

* **Monorepo tooling:** pnpm workspaces + Turborepo. Single `pnpm install` at root.
* **Public IDs:** every externally-exposed resource uses `publicId` (ULID) — internal `id` (serial) stays private. API never leaks sequential IDs.
* **Financial safety:** all money = `Prisma.Decimal` / `NUMERIC(20,8)` + ledger. No JS float math.
* **Provider/Reseller separation:** `apps/api` never calls provider from request path synchronously except for `Test Connection`; all order flows go via queues.
* **Storage:** S3-compatible via `@aws-sdk/client-s3` — same interface for R2/S3.
* **No license code:** installer has no license-key step; `APP_ENV=demo` gates demo restrictions purely via feature flags.
* **Secrets:** never in `packages/*` or `apps/web`; encrypted at rest in DB where practical (provider API keys, payment secrets).

## 9. What This Structure Deliberately Avoids

* No `plugins/` directory that executes uploaded PHP/JS.
* No `license/` module.
* No `cron/*.php` endpoints — all scheduling via BullMQ repeatable jobs.
* No frontend direct provider calls.
